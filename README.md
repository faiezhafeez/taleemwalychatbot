# Taleemwaly Chatbot 🇵🇰

Pakistan Education Assistant — Boards, Commissions, AIOU Services

## What is Taleemwaly?

"Taleemwaly" is an AI chatbot that helps Pakistani students with:
- 📚 All Boards (Punjab, Sindh, KPK, Balochistan, Federal, AJK)
- 🎓 AIOU services (assignments, guess papers, books, degree)
- 💼 Service Commissions (FPSC, PPSC, SPSC, KPPSC, BPSC, AJKPSC)
- 📝 Testing agencies (NTS, ETEA, OTS, PTS, PERA, IBA, STS)
- 🏛️ CSS, PMS, Armed Forces recruitment
